# WindowRanger 1.0.9

WindowRanger 1.0.9 keeps configured Quick Apps on the Shelf when their windows become available after startup or resume.

## Fixed

- Quick Apps discovered after an empty or unavailable startup scan are reclaimed for the Shelf before ordinary workspace layout can tile or park them.
- Resuming window management checks for missing Shelf ownership before applying workspace layout. Existing presented Shelf sessions and explicit Shelf commands keep their intended behavior.

## Diagnostics

- Focused-window reports retain the original resize evidence and explain why a window classified as fixed-size is waiting for recovery. This improves investigation of intermittent tiling problems; it does not establish that every reported tiling failure is resolved.

## Requirements and installation

Requires macOS 14 or later and Accessibility permission. Screen Recording permission is needed only for optional captured workspace previews.

Download `WindowRanger-1.0.9.dmg`, open it, and drag WindowRanger onto the Applications shortcut. A notarized ZIP, checksums and provenance manifest are also included. Existing users can use **Check for Updates…** once the feed is published, or run:

```sh
brew upgrade --cask appranger/tap/windowranger
```

## Known limitations

WindowRanger manages virtual workspaces within the current macOS desktop, rather than replacing native macOS Spaces. Fixed-size operation windows retain their existing protections.

Use the repository issue forms for privacy-safe feedback. Follow `SECURITY.md` for suspected vulnerabilities; do not include private diagnostics or window contents in public issues.
